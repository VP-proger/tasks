## 1. Как запустить

Нужен Python 3

Сначала запускаем сервер:

```
python server.py
```

Затем в отдельных терминалах запускаем столько клиентов, сколько нужно:

```
python client.py
```

## 2. Какие команды поддерживает программа

`/add <текст>` - добавить новую задачу,
`/list` - показать все задачи,
`/done <номер>` - отметить задачу как выполненную,
`/quit` - завершить работу клиента

## 3. Как реализована одновременная работа нескольких клиентов

Главный поток сервера в бесконечном цикле ждет подключений.
Когда клиент подключается, сервер создаёт для него отдельный поток threading.Thread с функцией handle_client.
Пока один поток ждет сообщение от своего клиента, остальные потоки спокойно обслуживают других клиентов, поэтому клиенты не блокируют друг друга.

Список задач tasks создан один раз на уровне модуля и общий для всех
потоков, поэтому все клиенты работают с одними и теми же данными.

В клиенте тоже два потока: главный читает ввод пользователя и отправляет
команды, а фоновый все время принимает ответы сервера и печатает их.

## 4. Где и зачем используется синхронизация

Общий список tasks читают и изменяют сразу несколько потоков, поэтому он защищен замком tasks_lock = threading.Lock(). Все обращения к списку
(`/add`, `/list`, `/done`) выполняются внутри with tasks_lock:.

Замок нужен потому, что многие операции состоят из нескольких шагов.
Например, при `/add` нужно добавить задачу и узнать ее номер, а при
`/done` сначала проверить, что задача с таким номером существует, и только
потом отметить ее. Если между этими шагами вклинится другой поток, номера
могут оказаться неверными, а проверка устареет. Поэтому проверка и
изменение выполняются под одним захватом замка. Список при `/list` тоже
собирается под замком, чтобы другие потоки не меняли его во время чтения.

Отправка ответа клиенту выполняется уже вне замка, чтобы клиент
не заставлял остальные потоки ждать.
